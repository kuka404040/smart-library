# Smart Library — Цифрлық кітапхана (College Edition)

Заманауи, қарапайым және ыңғайлы колледж кітапханасының жүйесі.
Жүйеде 2 рөл бар:
1. **Студент** — тіркелусіз және авторизациясыз кітаптарды қарайды, іздейді, AI Smart Search пайдаланады, қолжетімді дана санын көреді.
2. **Кітапханашы** — `/admin` арқылы құпиясөзбен кіреді (бөлек админ-панель жоқ, барлық басқару осы бетте пайда болады), кітап қосады/өңдейді/жояды, кітапты топқа береді және қабылдайды, жартылай қайтаруды жүргізеді, тарихты бақылайды.

---

## 1. Windows жүйесінде жылдам іске қосу (1-тәсіл: Node.js Fullstack)

Бұл тәсілде сервер мен интерфейс бірден іске қосылады (SQLite деректер қоры автоматты түрде дайындалады):

1. Компьютерде **Node.js** орнатылғанына көз жеткізіңіз (ресми сайт: [nodejs.org](https://nodejs.org/)).
2. Жоба бумасында `run_windows.bat` файлын екі рет басып іске қосыңыз немесе терминалда (PowerShell/CMD) келесі пәрмендерді орындаңыз:
   ```bash
   npm install
   npm run dev
   ```
3. Браузерді ашып, мына сілтемеге өтіңіз:
   - **Студенттер үшін:** `http://localhost:3000`
   - **Кітапханашы үшін:** `http://localhost:3000/admin`
   - **Әдепкі құпиясөз:** `admin123`

---

## 2. Python FastAPI + Ollama арқылы іске қосу (2-тәсіл)

Егер сіз Python + FastAPI + Ollama (nomic-embed-text) арқылы бөлек backend қосқыңыз келсе:

### А. Ollama және nomic-embed-text моделін орнату:
1. [ollama.com](https://ollama.com/) сайтынан Ollama орнатыңыз.
2. Терминалда модельді тартып алыңыз:
   ```bash
   ollama pull nomic-embed-text
   ```

### Ә. Python тәуелділіктерін орнату және серверді қосу:
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

## 4. Негізгі артықшылықтар

- **Жартылай қайтару:** 25 кітап беріліп, 23-і қайтарылса, жүйе қалған 2 кітаптың қарызда екенін нақты көрсетеді.
- **Нөлдік галлюцинация (AI):** AI Smart Search тек SQLite деректер қорындағы нақты кітаптарды табады, жоқ кітаптарды ойдан шығармайды.
- **Тіл ауыстыру:** Қазақша және орысша (ҚАЗ / РУС) лезде ауыстыру.
- **3D Book Loader:** Кітап парақтарының ашылуымен ерекше жүктелу анимациясы.
